# Super Clipboard-Snippet for Omarchy

Clipboard history and snippets in one picker for the [Omarchy](https://omarchy.org) shell. It opens on two tabs, **Clipboard** and **Snippets**, switched with the `←` / `→` arrow keys. The Clipboard tab has fuzzy search across content, type, app and date (`type:image`, `app:firefox`, `<2h`, `is:pinned`), pins, rich per-type previews, and OCR and QR decoding of copied images. The Snippets tab keeps templates with a name, a short slug to find them, and Markdown text with date and time variables (`{date_long}`, `{time}`…) that are filled in when pasting; a small popup at the mouse (for example on Ctrl+Space) searches and pastes them from any app. Shortcuts, import/export of snippets and settings, and everything else live in the in-picker Settings. The interface is in English by default, with Spanish available in Settings. It replaces the built-in `omarchy.clipboard`, so its usual shortcut opens this picker, and it keeps all of its data in its own folder (`~/.local/state/omarchy/super-clipboard-snippet/`). It is built on [alanfortlink/clipboard-history](https://github.com/alanfortlink/clipboard-history) (MIT).
